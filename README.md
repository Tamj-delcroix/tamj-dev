# Tamj.dev

A personal link-in-bio website built to showcase my online presence, social media, and projects in one place.

## ✨ Overview

Tamj.dev is a simple personal landing page designed to provide visitors with quick access to my social profiles, GitHub, and contact information.

## 🚀 Features

- Personal profile and introduction
- Social media links
- GitHub profile access
- Contact links
- Responsive layout for different screen sizes
- Custom styling and interactive elements

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript

## 📁 Project Structure

```text
tamj-dev/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 💻 Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/Tamj-delcroix/tamj-dev.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

No package installation is required for the basic static website.
